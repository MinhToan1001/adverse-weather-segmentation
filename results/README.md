# `results/` — committed experiment evidence

This directory holds **small, reviewable evidence** only. Raw datasets, checkpoints and large dumps stay local or become GitHub release assets.

## Layout

| Path | Contents |
|---|---|
| `baseline/` | Cityscapes val metrics, history, run cards, checkpoint SHA-256 |
| `dg_eval/` | One-shot ACDC val metrics (per condition, per class), bootstrap CIs |
| `ablation/` | Controlled baseline-vs-extension tables and run IDs |
| `tables/` | Rendered Markdown/CSV tables used in the report |
| `figures/` | Prediction grids, per-class bars, failure cases (PNG ≤ 2 MB) |
| `demo/` | Demo inputs/outputs and screenshots |

## Rules

1. **CSV is the source of truth.** Every number in the report must be traceable to a CSV generated by committed code and a run card.
2. **Naming:** `<gate>_<dataset>_<split>_<run_id>.csv`, e.g. `dg_acdc_val_seed42_r01.csv`.
3. **Every CSV** starts with `run_id,git_commit,config_hash,checkpoint_sha256,dataset,split,domain,seed`.
4. **Never commit** `*.pt`, `*.pth`, `*.ckpt`, `*.safetensors`, raw images, masks or archives. They are git-ignored; use a release asset and reference its hash.
5. **No overwriting.** A corrected run gets a new `run_id`; the old file is kept and marked `status=invalid` in its run card.
6. **One-shot target rule:** ACDC val is evaluated once with the frozen baseline. Exploratory re-runs are labelled `exploratory` in `run_id` and must not replace the primary row.
7. Files ≤ 2 MB. Larger figures belong in a release or are downsampled.

See `docs/experiment_protocol.md` for the protocol that produces these artifacts.
